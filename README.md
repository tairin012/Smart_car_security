# Car Security and Monitoring System

An IoT-based vehicle monitoring and crash detection system built using NodeMCU Mega WiFi R3 (ATmega2560 + ESP8266).

## Features
- **Fuel Theft Prevention:** Micro limit switch on the fuel door alerts via Blynk and LCD.
- **Crash Detection:** MPU-6050 accelerometer detects sudden impacts and displays an alert.
- **Speed Calculation:** Hall effect sensor calculates real-time wheel RPM and km/h.
- **Obstacle Warning:** Ultrasonic sensor warns when objects are within 10 cm.
- **Remote Control:** 4-wheel directional movement using the Blynk mobile app.

## Components Used
- NodeMCU Mega WiFi R3 (ATmega2560 + ESP8266)
- MPU-6050 Gyroscope/Accelerometer
- Hall Effect Sensor
- Ultrasonic Sensor (HC-SR04)
- Micro Limit Switch
- 16x2 I2C LCD Display
- L298N Motor Driver + 4 DC Gear Motors
